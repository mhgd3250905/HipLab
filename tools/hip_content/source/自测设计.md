# HipLab 第 0 阶段 · 自测设计（开胯体检）+ 安全规则

> 2026-10-16（同日修订：开哥拍板内收并入主流程，自测 6 项、约 3 分 30 秒；MVP 隐藏健身房场景）· 设计原则：小白 3 分半自己做完；**看动画学动作、点图片选结果**，不让用户读长段文字、不输入角度、不拖滑块。
> 配套：`动作清单与缺口.md`、`成套训练.md`、`髋部动作表.csv`。

## 1. 整体流程（约 3 分 30 秒）

```
[3 张安全图卡] → ① 蝴蝶式 → ② 90/90 → ③ 托马斯（左/右）→ ④ 仰卧横跨（左/右）→ ⑤ 坐姿前屈 → ⑥ 深蹲 → [雷达图 + 推荐]
   约 15 秒        30 秒      40 秒        40 秒                35 秒                 25 秒        25 秒
```

顺序按"少换姿势"排：坐 → 坐 → 躺 → 躺 → 坐 → 站。④ 内收紧跟 ③ 托马斯，用户躺着不用起身；合计约 210 秒 ≈ 3 分 30 秒。

每一项的屏幕都一样，三步：
1. **看**：上半屏循环演示动画（3–4 秒一圈），自动播放，配一句语音口令。没有文字说明段落。
2. **做**：用户照着做，屏幕上一个圆环倒计时（10–15 秒）。语音提醒"停在这里，看一眼你的膝盖"。
3. **选**：下半屏 3 张对比图横排（同一个人体模型、同一机位、只改姿势），点"像哪张"。图下面各一个小字标签（"贴地 / 一拳 / 翘起"），只做辅助。另外有一个小按钮 **"做的时候疼"**（红色小图标，不是第 4 张图）。

规则：
- 每张对比图都是用同一套 drill-anim 管线渲出来的静帧，目标位置用方案 B 发光标出（例：蝴蝶式就让膝盖附近发光），一眼知道该看哪。
- 左右都要测的项（②③④）自动换边，换边时动画镜像。
- 中途可以"跳过这项"：跳过的那项按"一般（1 分）"计入，结果页在对应方向旁标一个小字"未测"，下次复测再补。
- 一共 **6 项**，雷达图 6 个方向都由主流程测出；进度点 6 个（原型 s2 已改为 1/6）。

### 对比图的打分
每项 3 张图从左到右固定是：**A 松（2 分）· B 一般（1 分）· C 紧（0 分）**。点"疼"记为 **P**（不计分，触发安全规则，见第 4 节）。

## 3. 结果怎么变成雷达图、路线和起始难度

### 3.1 方向得分
每项结果 A=2 / B=1 / C=0，按权重算 6 个方向（0–2 分，6 个方向都有实测来源），再映射到雷达图：0 → 25、1 → 60、2 → 90（满分 100 留给复测进步）。

| 方向 | 来源与权重 |
|---|---|
| 屈 | ⑤ 坐姿前屈 60% + ⑥ 深蹲 40% |
| 伸 | ③ 托马斯 100% |
| 外展 | ① 蝴蝶式 70% + ⑥ 深蹲 30% |
| 内收 | ④ 仰卧横跨 100% |
| 内旋 | ② 90/90 后腿 100% |
| 外旋 | ② 90/90 前腿 60% + ① 蝴蝶式 40% |

结果页（同样图优先）：雷达图 + 最低的 1–2 个方向用一张人体小图标出（髋部对应区域发光），配一句话："你的髋前侧最紧，先从这里开始。"不展示分数表。

### 3.2 推荐路线
首次打开时用户已经选过身份（3 张图：**坐办公室的人 / 跳舞的人 / 都不是**）。路线 = 身份 × 最低方向：

| 最低方向 | 上班族 / 都不是 | 舞者（Breaking） |
|---|---|---|
| 伸 | 久坐解压（髋前侧） | Breaking 开胯 · 先补髋前侧（L 撑） |
| 屈 | 深蹲到底 | Breaking 开胯 · 压缩（L 撑 / V 撑） |
| 外展 | 盘腿自如 → 横叉 | Breaking 开胯 · 分腿（风车 / 托马斯腿部绕环） |
| 外旋 | 盘腿自如 | Breaking 开胯 · 分腿 |
| 内旋 | 内旋补强（MVP 里作为"今日训练"的重点方向，不单独成路线） | 同左，加到舞者路线的每次训练里 |
| 内收 | 髋外侧放松：今日训练重点方向（不单独成路线），主选 `o-stand-crossreach`（拉伸）+ `h-supine-twist`（放松）+ `n-seated-squeeze`（力量），办公椅场景三个都能做 | 同左，加进舞者路线的每次训练（风车 / 托马斯腿部绕环的收腿需要髋外侧） |

- 两个方向并列最低时，优先级：**伸 > 内旋 > 外展 > 屈 > 外旋 > 内收**（久坐人群最常见、最影响日常的排前面；内旋是我们的差异点）。内收现在是实测值，可以成为最低方向，但 MVP 的内收动作只有 3 个，所以并列时排最后。
- 内收和外展同时最低（④ C + ① C）时，按外展出路线，内收动作作为每次训练的固定 1 个附加动作。
- "今日训练"按 60% 重点方向 + 40% 其余方向轮换生成，场景开关（**办公椅 / 居家**，MVP 隐藏健身房）决定从哪一列取动作。
- "左右不一样"：在该方向的单侧动作上，紧的一侧多做 1 组，播放器提示"右边多做一组"。
- 8 周目标路线是第二版功能；MVP 里路线 = 今日训练的选材规则 + 成套训练的推荐顺序。

### 3.3 起始难度
总分 = 6 项之和（0–12）。

| 总分 | 起始档 | 动作池 | 练法配比（放松 / 柔韧 / 主动控制 / 力量） |
|---|---|---|---|
| 0–5 | **L1 入门** | 只用"入门"动作；进阶动作全部自动换成替代 | 30 / 50 / 15 / 5 |
| 6–9 | **L2 基础** | 入门为主，可出现 1–2 个进阶 | 20 / 40 / 25 / 15 |
| 10–12 | **L3 进阶** | 入门 + 进阶都可用 | 10 / 30 / 35 / 25 |

额外规则：
- 任一项点了"疼"：那个方向**锁定在 L1、只出放松动作**，直到下次复测这一项不再点"疼"（见第 4 节）。
- 舞者身份且总分 ≥10：解锁托马斯库 T 系列（分腿支撑等）。
- **进阶**（每周复测后判断）：某方向升 1 档（例 B → A），或者 2 周内完成率 ≥70% 且没有点过"疼"，那个方向升一级难度。降级只由疼痛规则触发，复测分数下降不自动降档（避免一天状态不好就打击用户），改为提示"今天先轻一点？"。

### 3.4 需要新做的素材
- 6 项 × 3 张对比图 = 18 张，+ ② 追问 2 张 = **20 张静帧**（总数不变）；
- 1 段新动画（`n-thomas-test`）+ 1 段演示片段（`n-leg-circles` 加横跨 clip），其余 4 段演示复用现有 spec；
- "做的时候疼"图标、身份 3 张图、安全图卡 3 张（见下）。

## 4. 安全：禁忌提示与疼痛降级

### 4.1 措辞规矩（全 App 适用）
- **不说**：治疗、康复、理疗、矫正、治愈、缓解疼痛、诊断、处方、改善 XX 症状。
- **说**：放松、舒展、活动度、练习、"感觉更轻松"、"髋部更灵活"。
- 疼的时候**绝不说**"忍一忍""再坚持一下""疼说明有效"。统一用"别勉强"。
- 定位写成"运动指导 / 日常活动练习"，不碰医疗表述（App Store 健康类审核）。

### 4.2 首次启动：3 张安全图卡（图 + 一句话，点"有 / 没有"）
| 图卡 | 内容 | 选"有"之后 |
|---|---|---|
| 1 | 孕期或产后 6 个月内 | 提示"先问问医生或专业人士，再开始练习"；可以浏览动作，但**不生成训练**、不做自测 |
| 2 | 髋 / 膝 / 腰做过手术或关节置换，或者医生让你限制活动 | 同上 |
| 3 | 最近摔伤、扭伤，或者髋部 / 腰部 / 大腿正在疼、肿 | 同上；另提示"等不疼了再来做自测" |

图卡之后一行小字："这是运动练习，不能替代医生的建议。"选"没有"直接进入自测。这 3 张卡在设置里可以重新看、重新选。

### 4.3 练的时候怎么分"拉伸感"和"疼"
播放器里不写文字解释，用 2 张小图标 + 语音一句：
- **拉伸感（可以）**：肌肉被拉长、均匀的紧，松开就消失。图标：拉长的橡皮筋（绿色）。
- **疼（停）**：关节里面疼、夹着疼、刺疼、发麻、疼往腿上窜。图标：闪电（红色）。

每个动作做完，底部 3 个大按钮：**舒服 / 有点紧（正常）/ 疼**。选"疼"时再弹一次：**"是关节夹着疼"** / **"是麻、刺、往下窜"**（2 张图）。

### 4.4 疼痛降级阶梯
| 触发 | 动作 |
|---|---|
| 某动作第 1 次点"疼"（夹痛） | **降一档**：同一动作换小幅度版本（动画幅度减半、时间减半），语音"幅度小一点，别勉强" |
| 降档后还疼，或同一次训练里同方向第 2 次"疼" | **换动作**：换成挂好的同方向、更简单的替代（例：`s-pigeon` → `s-figure4`；`h-couch-stretch` → `s-kneel-hipflex`；`h-sumo-pry` → `h-wall-straddle`；`n-half-split` → `o-seated-ham`） |
| 替代动作还疼 | **跳过这个方向**：今天剩下的训练里这个方向只出放松动作 |
| 7 天内同一方向 2 次走到"跳过" | 这个方向**锁定 7 天只放松**，首页出一张卡："这里连续不舒服，建议问问医生或专业人士。" |
| 任何时候选"麻、刺、往下窜" | **立刻结束本次训练**，显示同一张建议卡；下次打开先问一句"现在还麻吗？"（是 / 否） |
| 自测时点"疼" | 该方向记为"疼"，锁 L1 + 只放松，结果页不给分、显示为黄色"先别练这里"，下次复测再判断 |

### 4.5 动作层面的常见"别勉强"提示（挂在动作数据上，播放时语音说）
| 情况 | 涉及动作 | 提示与处理 |
|---|---|---|
| 髋前侧夹着疼（深屈髋） | 抱膝、深蹲、相扑蹲、青蛙、宽膝抱膝 | "膝盖分开一点，别抱那么紧" → 减幅度 |
| 膝盖内侧 / 外侧疼（扭力） | 90/90、鸽子式、蝴蝶式、4 字 | 换 `s-figure4` 仰卧 4 字（膝不受扭力） |
| 大腿根内侧刺痛 | 横叉类、哥萨克蹲、哥本哈根、滑垫侧滑 | 立即减幅度；当天不再出横叉类 |
| 腰疼 | 沙发拉伸、弓步、蜥蜴、臀桥、坐姿前屈 | "肚子收一下，屁股往下收" → 减幅度；还疼就换仰卧动作 |
| 跪着膝盖疼 | 半跪、沙发拉伸、四足类 | "膝盖下面垫一块毛巾" → 还疼换站姿版（`o-stand-lunge`） |

### 4.6 进阶护栏
- 横叉 / 竖叉进阶动作（`n-slider-lateral`、`n-supported-front-split`、托马斯库 T 系列）需要：对应方向自测 ≥ B，且最近 2 周该方向没点过"疼"。
- 力量动作不加外部负重；弹力带动作都给"无带版本"。
- 每次训练开头固定 1 个放松或主动控制的热身动作，不直接上最大幅度拉伸。
