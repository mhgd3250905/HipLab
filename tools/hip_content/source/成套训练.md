## 编排规则（所有套通用）

1. **先动后拉**：每套第 1 个动作是放松或主动控制（骨盆画圈、髋 CARs、抱膝），不直接上最大幅度的拉伸。
2. **同侧连做**：单侧动作先右后左，播放器自动镜像，中间不插别的动作，省掉来回换姿势。
3. **少换姿势**：同一套里按"站 → 坐 → 跪 → 趴 / 躺"或者反过来排，不来回起身（睡前套全程躺着、只在最后挪到墙边，办公室套不坐地）。
4. **按难度自动换**：用户在 L1 时，表里标"进阶"的动作自动换成"L1 替代"那一列；L3 时可以把同方向的入门动作换成进阶版。
5. **按自测加量**：自测"左右不一样"的方向，在这套里紧的一侧多做 1 组（时长自动 +1 组）。
6. **按疼痛降级**：任何动作点"疼"，按 `自测设计.md` 第 4.4 节的阶梯处理；降级后的替代动作就用表里"L1 替代"那一列，不另找。
7. **场景开关**：MVP 只有**办公椅 / 居家**两个场景（健身房开关隐藏，开哥 10-16 定）。办公室套（A、M）固定在办公椅场景，其余 5 套（B–F）为居家场景。4 个 C 档器械动作（hip-abductors-C / adductors-C / hip-flexors-C / glute-max-C）标为二期，任何一套都不使用。
