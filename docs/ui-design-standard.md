# HipLab UI 设计规范

本文件记录 App 的**设计标准**。界面按这里规定的数值实现。通用顶栏沿用 2026-11-05 开哥逐屏确认的形制，见 [hip_page_kit.dart](../lib/hip/ui/hip_page_kit.dart)。

历史阶段记录、验收证据和失败现场仍写进对应的日期文档与台账；本文件只保留当前应当被遵守的规则。

跨App实现方法、依赖边界、完整Flutter样例与迁移验证见[UI实现与复用手册](ui-kit/README.md)。本文件规定项目数值，手册解释实现；更改数值须同步两者。通用界面规则沿用 main 接收的 +61 验收基线。会员页以第 7 节的 v2 规范为准。

## 1. 顶部导航栏（HipNavBar）

### 1.1 结构

```
┌─────────────────────────────┐  y = 0   屏幕最顶（状态栏背景）
│  状态栏                       │
├─────────────────────────────┤  y = 状态栏高
│  (返回胶囊)   标题    (操作)  │  44pt 标题行（有副标题时 52pt）
├─────────────────────────────┤  y = 状态栏高 + 44
│  ·                          │  ·  24pt 过渡段（kHipNavFade）
│  ·     向下渐隐至全透明        │  ·
└─────────────────────────────┘  y = 带底
```

- 条带总高 = 状态栏 + 标题行 + `kHipNavFade`（24）。
- 内容视口从 **屏幕 y = 0** 开始，列表一直滚到状态栏下面（对齐 Gemini / iOS 的行为）；页面自己在滚动内容顶部留出 `hipNavInset(context)` = 状态栏 + 44 + **24 过渡段**；有副标题时显式调用 `hipNavInset(context, hasSubtitle: true)` = 状态栏 + **52 + 24**。静止时首行必须在渐变带以下，否则会被磨砂压暗、看不清。
- 条带是**浮层**：`IgnorePointer`，不拦截滚动；只有返回胶囊和右侧操作可点。
- 无分割线、无投影、无圆角。

### 1.2 材质（关键）

顶栏背景 = **用页面背景色直接绘制的竖向渐变 + 三层渐进模糊**，不是实时高斯"玻璃块"，也不是把页面背景复制一份压上去。

渐变透明度曲线（`_HipBarGlass._fade`，t 为 0..1 的带高比例）：

| 区间 | 曲线 | 说明 |
|---|---|---|
| `0 ≤ t ≤ 0.6` | `α = 1 − (1 − 0.86)·(t/0.6)²` | 顶部全不透明，缓降到 0.86：保留"些许透明、透光模糊" |
| `0.6 < t ≤ 1` | `α = 0.86 · (1 − u²)`，`u = (t−0.6)/0.4` | 抛物线加速，t=1 时归零 |

- 拐点 **60%**（`_knee = .6`），拐点透明度 **0.86**（`_kneeAlpha = .86`）。
- 用 12 段采样近似曲线（`_samples = 12`）。
- 颜色 = `HipColors.background`（浅色 `#f4f5f3` / 深色 `#0c0d0f`），不额外加白或加黑。

模糊层（同一曲线族，越靠上越厚）：

| σ | 收干净的位置 |
|---|---|
| 34 | 带高 78% |
| 20 | 带高 90% |
| 9 | 带高 100% |

三层模糊必须位于与条带实际尺寸一致的显式 `ClipRect` 内（状态栏 + 44/52pt 标题行 + fade）。`SizedBox`、`Stack` 和 `RepaintBoundary` 只限定布局/分层，不能代替滤镜的绘制裁剪；否则双页转场会重复采样整个视口。保留上述三层参数和固定返回胶囊，不给相互重叠的模糊层共用 `BackdropKey`。

高对比度模式：**不采样**，直接用不透明背景色渐变（`α ≈ .96 → 0`）。

### 1.3 控件

| 元素 | 规格 |
|---|---|
| 标题 | 17pt / w600 / `HipColors.text`，居中，单行省略；副标题 12pt / `HipColors.muted` |
| 返回 / 关闭胶囊 | 直径 **44pt**，字形 **32pt**（24 网格描边 2.0）。`_HipChipSurface` 为平整磨砂玻璃：统一半透明填充（浅色 `white @ .38` / 深色 `white @ .12`）+ 真实 `BackdropFilter` 模糊 σ12 + 0.75pt 细边（浅色 `black @ .10` / 深色 `white @ .16`）；**无渐变、无内阴影、无投影**，不与条带做 z 轴分离。高对比度：不透明底（浅色纯白 / 深色 `#FF1C1C1E`）+ 1pt 描边（`black @ .35` / `white @ .45`），不采样不模糊 |
| 胶囊热区 | 44×44，左边缘距屏 16pt |
| 右侧操作 | 单个文本或图标，宽度 ≤ 44pt |
| 标题左右安全区 | 各 60pt |

返回/关闭胶囊的顶部始终位于状态栏安全区下缘，固定44pt控制轨道；有副标题时仅标题和磨砂条带增高到52pt，不再将胶囊向下居中。右侧操作同样在44pt控制轨道内居中。固定胶囊与随页滑入的胶囊必须使用相同纵向锚点，单行/双行标题互相切换及键盘出现均不得改变按钮高度或直径。

### 1.4 页面接入

```dart
HipNavPage(
  title: '设置',
  bodyScrollsUnderBar: true,   // 视口顶到屏幕 y=0，内容从条下滑过
  body: ListView(
    padding: EdgeInsets.fromLTRB(20, hipNavInset(context) + 12, 20, 24),
    ...
  ),
)
```

- `bodyScrollsUnderBar: true` 时必须用 `hipNavInset(context)` 给内容留出顶部 inset；有真实副标题的动作/套路详情、加动作选择器和自测结果传 `hasSubtitle: true`。该值已包含 `kHipNavFade`，不要再用裸的状态栏 + 44。
- `bodyScrollsUnderBar: false` 用于固定头部/表单页：内容从条底开始，条带不向下延伸（`fade = 0`）。
- 带底部操作条的页面通过 `bottomBar` 传入，底部安全区由操作条自己负责，页面内容区不再重复留底。键盘的 `viewInsets.bottom` 由 `HipNavPage` 在 `bottomBar` 外统一补一次，页面或 `LibFooter` 不再重复补键盘高度；按钮必须保持在键盘上方。
- 评估页结果、编辑页等复杂页面允许使用 `bottomBar` 固定操作区；滚动内容仍走 `body`。

下列常规页面使用 `HipNavPage`，不直接拼接 `HipNavBar`：

| 模式 | 页面 |
|---|---|
| 内容穿透（true） | 更多、设置、训练记录、隐私政策、动作详情、套路详情、加动作选择器、自测说明、自测结果 |
| 固定头部（false） | 动作库/训练组（搜索或分段保持固定头部）、组编辑（名称/休息固定区）、安全提示复审、Coach 加载/错误壳 |

自测说明由 `HipAssessmentIntro` 持有唯一页面骨架，正文为可滚动列表、顶部 `hipNavInset + 12`，开始/重测操作放入 `LibFooter`。自测题目保留沉浸式单屏布局和原判断，仅用 `HipTopBar.leading` 接入 `HipNavBackChip(leading: HipNavLeading.close)`，不套浮动标题栏。首页、首次引导和 SDK 训练/聊天保持各自已确认边界。

沉浸自测头部保持原8pt外部顶留白及48pt控制轨道，44pt关闭胶囊固定在轨道内（顶部再留2pt）。问题标题换行或增高只扩展文字区域，左侧关闭和右侧进度不得跟随整行增高而下移。

### 1.5 路由过渡

- **所有 `HipNavPage` 目的页用 `HipRoute.content`**，不要用 `HipRoute.push`。整页表面——背景、body、bottomBar，以及顶栏的玻璃、标题、右侧操作——按路由时钟从右侧整屏滑入，返回时反向滑出并露出上一页。
- **只有前后两页都有返回胶囊时，胶囊才固定在原位**。此时 `HipNavPage` 把胶囊单独画在滑动层之外，滑动层里的 `HipNavBar` 用 `showLeading: false` 只画玻璃、标题和操作；被覆盖的页面会隐藏自己的胶囊，因此转场中始终只有一个返回胶囊，返回时也不会先淡成空背景再切换页面。
- 从首页等没有返回键的页面进入时，用 `HipRoute.content(..., pinLeading: false)`：目的页胶囊随顶栏一起滑入、返回时一起滑出，不会在点击瞬间先出现在左上角。
- 缓动与其它页面一致：进入用 `HipMotion.enter`、返回用 `HipMotion.exit.flipped`（400 / 340ms），不再用前段过快的 ease-out；iOS 边缘返回拖动时按手指 1:1，不套曲线。
- 下层页面以 -28% 视差左移并轻微压暗，跟随上层页面一起进退。
- iOS 左缘右滑返回保留；Android 系统返回手势照常 pop。
- `HipRoute.push` 只用于没有共用顶栏的沉浸页；`rise`/`expandFrom` 仍用于训练与容器变换，自测从开始按钮展开的流程保持。
- 系统开启"移除动画"时直接落到终态，不做位移与淡入；开关、分段、按压、状态切换和确认弹窗也不留下过渡动画。iOS 左缘返回手势仍可用，拖动不移动页面表面，结束时以零时长完成或取消返回。

```dart
Navigator.of(context).push(HipRoute.content<void>((_) => const HipSettingsPage()));
```

## 2. 分组列表与设置条目

### 中英文界面

界面语言独立于口令语言，设置提供“系统 / 中文 / English”，沿用旧安装默认中文。界面与 SDK 展示按 Flutter 已解析 locale 渲染；系统语言不支持时回落中文。语言切换保留当前页面、训练组与对话，不翻译用户命名和历史聊天原文；内置计划记录可按来源ID展示对应译名。

英文设置中的长标题与三段选择器分行呈现，保持原图标列与控制尺寸。首页英文计划标题允许两行，动作牌的文字度量使用本地化后的内容，牌面抬头在44pt区域内必要时等比缩小。不得为切语言重建视频播放器或改变翻牌身份。

公共动作说明采用 App 拥有的逐条英文展示数据，与冻结 canonical 来源关联；显示译文不改动作ID、计量、筛选语义值、评分或安全准入。目录将来更新时需要同步其英文说明，不能把本轮静态译文当作未来内容的自动翻译。

- 卡片：圆角 **10**，无描边、无投影；填充浅色 `white @ .7`、深色 `white @ .06`。
- 分隔线：0.5pt，`text @ .1`，从文字起点（`kHipRowTextInset = 16 + 30 + 12 = 58`）开始。
- 行：左右内边距 16，垂直 10；单行最小高 **52**，带副标题 **60**。
- 标题：**17pt / w400**；副标题 13pt muted；右侧 meta 14pt faint。
- 图标：**30×30**，统一使用 `HipRowEmblem` 立体矢量插画：玉绿、浅瓷、少量金属色，方向一致的高光、侧壁和微倒角。普通条目前导图标共18类，由 `HipRowIcon` 统一映射；“设置”用齿轮，“颜色”用明暗球体，避免共用同一符号。音量及添加动作时的训练组选择列表同样接入。图标是静态装饰，不新增按钮语义、动画或背景采样；行文字/分隔线位置保持。图标内部可用材质渐变，交互控件仍按既有玻璃规则。
- chevron：15pt，描边 2.0，`HipColors.faint`。
- 列表页**不再使用小标题**（"提醒 / 语音播报 / 外观 / 其他"已移除）：组间距 **28**，第一组距渐变带底部 12；页面顶部用 `hipNavInset + 12`。
- 内容型小标题仍可用于记录页图表、自测说明、练习页计数等非分组场景。

## 4. 实现约束（踩过的坑）

1. **不要用 `ShaderMask` 包一层"复制页面背景"来实现渐变。** 背景组件内部有 `RepaintBoundary`，Impeller 下遮罩会失效，正文会从"不透明"条带里透出来。
2. **不要把正文放进顶部 `SafeArea`。** 需要在条下滑动时必须从屏幕 y=0 开始布局，SafeArea 只保底边。
3. **不要用 `AnimatedOpacity` 包 `BackdropFilter`。** 分数透明度会生成离屏 alpha 层，背景滤镜采样不正确。
4. **不要重新引入"模糊 + 深色蒙版"的旧方案。** 会形成一条可见的色带，且随页面背景变绿/变灰。
5. 每个可见顶栏有3层`BackdropFilter`，真实采样裁剪为动态状态栏高度 + 44/52标题行 + 当前fade；双页转场可能同时存在两组，各自有局部paint clip，不能把层数固定理解成整屏永远3个。

## 5. 验收清单

- [ ] 静止时顶栏与状态栏同色，看不到任何色带或分割线
- [ ] 列表滚动时正文从状态栏下方穿出，顶部仍清晰可读
- [ ] 60% 拐点以下能看到"透光但模糊"的内容
- [ ] 条带底部完全透明，无硬边
- [ ] 深色主题下所有层级颜色反转正确
- [ ] 高对比度模式下不采样、不模糊
- [ ] 返回胶囊点击区域 ≥ 44×44，语义标签为"返回 / 关闭"
- [ ] 列表页无分组小标题，组间距 28，首组距条带 12
- [ ] 开关 / 分段 / 滑块在浅色与深色下均与 iOS 系统控件同一视觉家族
- [ ] 内容穿透页面静止时首行/首卡完全在渐变带下方
- [ ] 主/次按钮 50 高、圆角 14、17pt；确认弹窗无 Material 默认样式残留
- [ ] 前后页都有返回胶囊时只有胶囊固定；从无返回键页面进入时胶囊随页面滑入，顶栏玻璃/标题/操作始终随页面滑动，无双重胶囊或空背景闪烁
- [ ] 有副标题页面按 52 + 24 留白；自测说明滚动与固定底按钮互不遮挡
- [ ] 键盘出现后操作条仅上移一份键盘高度，保存/添加仍可点击
- [ ] 复合卡片的编辑与开始均可独立读屏激活；32pt 小玻璃按钮保持至少 44×44 热区
- [ ] 移除动画时无残留运动，iOS 左缘返回仍能完成或取消

## 6. 首页动作海报牌组

本节只作用于首页训练计划预览，保留其余页面的已确认主体语言。当前与已验收+61运行内容一致；旧截图/交接方案见历史交付，不作为当前实现规则。精确状态机、物理参数、同视频与冷首帧合同及文件夹示例见[媒体动效实现](ui-kit/04-media-motion.md)。

- 按实际计划顺序生成牌面，重复动作保留位置；预览不改训练顺序或持久化选择。静止最多三张，以旋转、透视、缩放和错位形成手持扇形层次；序号只显示单数字编号，读屏仍说明完整位置。
- 不显示“左右翻阅”提示或两侧箭头行，也不保留该行高度。前后牌共用布局、材质、媒体及标题比例，后牌到顶时不临时加控件/重排；阴影随depth连续衔接。
- 背牌可延伸至物理屏幕边缘，不在首页16pt内边距截出白色竖缝；只保留柔和接触阴影。底层新牌从原最底牌背后逐渐揭开，提交前已到最终位置，取消须完整撤回并精确归零；短牌组循环同样适用。
- 前牌在窗口浮层常驻，全向拖动允许覆盖标题和底栏。按用户最新决定撤回长按吸附，恢复原点按展开；按住不抬升，随后普通拖动仍跟手。任意方向超过窗口宽26%的径向距离均可翻牌：上/左主导看下一张，下/右主导看上一张；短拖、中央快甩或明显反向甩回原位。离场沿原射线，目标按投影边界到屏幕边缘的剩余距离计算；竖向k70/阻尼比.82形成加速与收势，保留真实甩速至2400，不将所有快甩硬压为900；水平k240/阻尼比1保持。完全离屏后及时解锁下一张。保留键盘方向键及读屏增减；更换计划重置，主题切换保留位置，减少动画直接切换。
