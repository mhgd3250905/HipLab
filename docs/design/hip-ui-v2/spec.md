# Hip 界面 v2 规格（开哥 2026-11-12 定稿）

范围：仅 Hip 本身。SDK（TrainerPlayer、TrainerPoster 渲染、CoachChatPage 布局）本阶段不动。
效果图：本目录 01–05 PNG（360×800 逻辑尺寸 ×3）。效果图中的数据为示意，以真实数据为准。
所有数值单位 dp/sp，不得自行发挥；与效果图冲突时以本文为准。

## 0. 全局（hip_theme / hip_page_kit / hip_widgets）
- 页面底：竖向渐变 #F8F9F7 → #EFF1EE，叠加极淡颗粒噪点（不透明度约 3%，可用一张平铺噪点 PNG）。
- 色：正文 #181E1C；次要 #7A837F；弱 #AAB1AE；品牌绿 P #14966F；深绿 DJ #0E6F56；开始/主按钮纯色 #16946F；暖橙（未完成）#C26A00。
- 绿色只用于：品牌小字、数值强调、选中态、开始键、链接文字。不得出现大面积绿色块（会员卡/会员按钮除外，见 §4）。
- 卡片 HipCard：白色竖向渐变 #FFFFFF → #FAFBFA；0.5 描边 黑 6%；内侧 0.5 白 78% 高光描边（内缩 1）；双层阴影：(0,1,blur 3, #14281F 5%) + (0,8,blur 28, #14281F 7%)。默认圆角 16。
- 圆形材质按钮（返回/关闭）：36（关闭 32），同卡片材质，阴影 (0,3,12, 7%)，图标 1.8 线宽正文色。
- 页标题：16 w700 居中。区块标题入卡内：13 w700 正文色，卡内边距 16，右上角辅助信息 12 w700 P。
- 卡内列表分隔：0.5 黑 5.5%，左侧缩进到文字起点。
- 字重对比：大标题 25–27 w700；正文 14.5–15 w600/700；说明 11–12.5 w400 次要色。

## 5. 真机验收修订

- 首页渐变和颗粒由整页背景绘制。卡堆的侧边仍在窗口边缘裁切，纵向保留卡片阴影的过渡。
- 无器械透明图的地影中心贴图中可见内容底边，宽为内容宽的 60%，高 10，`#14281F` 22%，模糊 5。带垫子或器械的图沿用原图。
- 单套训练组入口为 58×58、圆角 14 的白色材质，透明图按可见边界等比缩放至 44×44 内居中。多套保留 2×2，展开后的单张卡仍占一列。
- 会员已订阅卡副标题单行显示方案周期和 `YYYY-MM-DD` 到期日，后接「自动续订」「到期」或「起扣费」。网关剩余次数不可用时显示原问答说明。
- 第二张与前卡共享完整卡面，在圆角内绘制动作、地影、编号和说明，沿拖动进度归正。翻牌完成时沿用同一张卡面与媒体状态。第三、第四张只绘制不透明纸面和 0.5 黑 6% 描边。后卡静止角度为 −3.5°、−7°。底层绘制一份 (0,14,44, #14281F 13%) 软阴影，其余后卡只使用 (0,1,3, 5%) 接触阴影，前卡沿用原材质。
- 首页页头后留 20。以前卡宽高比 0.62、窗口两侧各预留至少 22 来确定基准尺寸，受宽度限制时等比收高。收起状态下前后卡宽高均为基准的 90%，前卡沿原中心缩放，上下各分配基准卡高 5% 的留白。分页点距卡底 26，点高 5，距训练组区为 6 加卡堆缩小后的下方留白。小屏实际卡高下限 360，整页可滚动。
