# App Icon：运动与开髋方向

2026-10-17，D-05。用户已否决前轮六个 IP 角色方案，明确要求由当前 HipLab 聊天重新设计：**简约、有质感，能表达运动，以及髋部和胯部的舒展柔韧。** 原 PR #4 已关闭，历史分支保留；本轮没有使用前轮图像作为参考，也未再委托该设计聊天。

设计采用青玉绿色简洁人体运动符号、石墨背景，以及髋部位置的近白色短弧。用平滑轮廓、浅浮雕厚度和克制光感形成质感，减少装饰、细碎结构和表情元素。

已交付两张原生 1254 × 1254 PNG：[A 蝴蝶坐姿舒展、B 站姿抬膝开髋](../design/app-icon/sports-20261017/README.md)。当前建议沿 B 收敛，因为腿部向外打开与髋部转折更能直接表达活动度和主动控制；最终选版仍待用户决定。

生成路径为内置 ImageGen，完整 prompt、来源和文件 SHA 已入候选目录。原计划的侧弓步版本被图像服务输出过滤拦截，没有返回图片；未重试，也未采用 CLI 或其他服务绕过。

当前仅设计与文档变化，未改代码、依赖、打包资源或版本，未构建和安装。选版后再完成图标工程资产、系统遮罩和小尺寸核验、Android 接入与实机展示。
