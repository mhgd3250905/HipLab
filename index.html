开胯训练助手 HipLab 隐私政策

生效日期：2026 年 10 月 17 日 · 适用范围：Android 应用「开胯训练助手」（包名 com.ugk.hiplab）

概述

「开胯训练助手 HipLab」由 Bboy Ug1yk 提供，面向成年人的日常髋部活动度和柔韧性练习。训练素材打包在应用内，无需连接外部服务器即可使用。开发者不通过本应用收集、上传、出售或分享你的个人数据，应用未集成广告、行为分析或崩溃数据收集 SDK。

本地记录与使用

训练计划、训练记录、身体自测记录和提醒设置保存在设备的应用私有存储中，用于在设备上提供训练安排和进度展示。开发者无法通过应用远程读取这些记录。本应用不要求注册账号，不通过应用收集身份信息、位置、设备标识符或使用行为统计。

系统备份、恢复与删除

Android 系统或设备厂商可能根据你的设备、系统版本、账号及备份设置，对应用数据进行系统备份，并在重新安装或迁移设备时恢复。此类备份由系统或相应服务提供方控制，不是开发者接收或存储你的数据。

清除应用数据或卸载应用会移除该设备上的应用本地数据；这不保证删除已有的系统或云端备份。若要同时删除备份，请在设备或备份服务的设置中管理、关闭或删除相关备份。重新安装后是否恢复记录取决于系统及你的备份设置。

权限与本机媒体播放

应用声明 Android 的普通 INTERNET 权限，用于在 127.0.0.1（本机回环地址）启动媒体服务，让应用内播放器读取随应用附带的素材。该媒体服务仅绑定本机，不用于向外部服务器上传训练记录、自测记录或其他个人数据。

本应用不请求定位、通讯录、相机、麦克风或共享存储等敏感权限。所有训练动作视频和图文素材均包含在应用内。

成年人健身与非医疗用途

本应用面向成年人提供普通健身练习，不面向儿童。动作引导、自测与进度信息仅供日常运动参考，不用于疾病诊断、治疗、医疗康复或医疗监测，也不能替代医生或其他专业医疗人员的建议。若出现疼痛、受伤或其他不适，应停止练习并寻求适当的专业帮助。

外部链接与主动联系

你主动通过电子邮件或 GitHub Issues 联系我们时，会向对应服务提供方及接收方提供你发送的内容和联系信息。请勿在公开 Issues 中填写敏感个人信息。邮件和 GitHub 的处理方式适用其各自的隐私政策。

政策变更

如本政策发生变化，我们将在本页面更新内容及生效日期，并使说明与应用的实际行为保持一致。
