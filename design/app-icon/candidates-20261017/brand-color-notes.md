# HipLab IP 品牌配色应用说明

HipLab 的青玉绿 `#3CCFA4` 适合承载“轻松舒展、身体活力、每天一点进步”的品牌感受。它比高饱和荧光绿更温和，又能在石墨背景中形成清楚的生命力；三个 IP 方向都以它为主体识别色。

深青绿 `#1F6F59` 用于角色的面部、腹部或身体内侧等大色区，强调稳定和主动控制，并为青玉主体建立清楚层级。石墨底方案中的浅薄荷白 `#DDF7EC` 则承担柔和面腹色区，让角色更有陪练伙伴的亲近感。每张只用两种角色语义色，不把所有品牌颜色一起堆上去。

背景对比采用两组：`#0C0D0F` / `#16171A` 的石墨色对应当前深色产品环境；`#F2F3F5` 的暖近白探索后续浅色环境。选定 IP 后，建议固定其主体色与五官关系，通过背景适配深浅环境，避免每次出现都更换角色本体颜色。

舒展精灵偏重弹性与舒展，小水獭偏重温和稳定的陪练感，萌芽伙伴偏重持续练习与渐进成长。青玉绿应作为三个方向共同的识别锚点；冰青 `#7BE8FF` 本批不作为必要色加入，以保持大色块简洁。

这些颜色表达训练体验和品牌气质，不构成医疗、安全或效果承诺。本轮只交付 IP 光栅候选及配色方向；选定后再制作矢量源文件、Adaptive Icon 前景/背景、Monochrome 与系统遮罩验证。
